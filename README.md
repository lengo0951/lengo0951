### 💫 About Me

- 🔭 **Featured Project:** Creator of [**PasteFlow**](https://github.com/lengo0951/PasteFlow) — a next-generation, ultra-lightweight clipboard manager natively built with **Swift 6 (macOS)** and **Rust 2024 (Windows)**.
- 🛡️ **Cybersecurity Research:** Specializing in Vulnerability Research, Binary Fuzzing (AFL++, LibFuzzer), Intrusion Detection & Prevention Systems (IDPS), Malware Analysis, and Exploit Development.
- ⚡ **Performance Obsessed:** Strict zero-bloat mandate — no Electron or heavy webviews. Pure compiled native binaries with minimal memory footprint (< 35MB RAM) and zero idle CPU.
- 🧠 **AI & LLM Security:** Researching LLM-driven adversarial testing, intelligent honeypots, and AI code security.
- 📍 **Location:** Ho Chi Minh City, Vietnam.
- 💬 **Ask me about:** Systems Programming, C/C++, Rust, Swift, Binary Exploitation, Fuzzing, Reverse Engineering.
